# Library Book Lending & Reference Analytics Platform

## Project Overview
This project is a Library Book Lending & Reference Analytics Platform designed to manage library users, books, lending and returns, and analytics.

## Major Functional Modules
1. User Management
2. Book Catalog & Search
3. Lending & Returns
4. Analytics & Reporting

## Agile Project Management
The project is planned and managed using Plane.

## Epics
- User Management & Authentication
- Book Catalog & Search
- Lending & Returns
- Analytics & Reporting

## Sprint 1
### Sprint Name
Sprint 1 – Core Setup and Book Search

### Sprint Goal
Develop the foundation of the system with authentication and book catalog/search features.

## Sprint 1 Features
- User Registration
- User Login
- Add Book Functionality
- Search Book by Title
- Search Book by Author
- Search Book by Category
- View Book Details
- Display Availability Status
